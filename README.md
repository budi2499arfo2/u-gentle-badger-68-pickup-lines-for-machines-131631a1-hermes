One pickup line one AI agent would send another, in the language of
calling and answering: polling an endpoint, waiting on a response code.

Run `python3 main.py` — it writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`) and verifies
the read-back byte-for-byte.
